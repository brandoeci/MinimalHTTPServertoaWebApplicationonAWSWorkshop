Sequential HTTP server

This page, its stylesheet, its script and both images were served by a Java server built on plain sockets. Each one of them was a separate HTTP request, answered one after another. The buttons below call the server's services asynchronously: the page is never reloaded.

Services

Greeting

GET /app/hello?name=...

Square

GET /app/square?value=...

Server time

GET /app/time

Slow service

GET /app/slow?millis=5000 — open a second window and call another service while this one runs.
